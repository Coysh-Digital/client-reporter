# Analytics integrations

The analytics integrations pull traffic and audience data into Client Reporter so it can appear in your client reports.

Client Reporter bundles integrations for three analytics providers: Google Analytics 4, Plausible and Fathom. Each connects using the provider's own API and authentication method, then collects the metrics that power the analytics blocks in a report.
